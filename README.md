# Portfolio – Wassila Et-toumi (React + Tailwind + Framer Motion)

1. Installer Node.js (https://nodejs.org), puis dans ce dossier :
   npm install
   npm run dev        # voir le site sur http://localhost:5173
2. Mettre ta photo (idéalement fond transparent) dans public/photo.png
3. Modifier ton contenu dans src/data.js (projets, liens, chiffres)
4. Publier : npm run build, puis déposer le dossier dist sur Netlify,
   ou connecter le dépôt GitHub à Vercel (gratuit).
